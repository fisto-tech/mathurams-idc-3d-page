# 3D Bed Product Configurator

Interactive 3D product visualizer for Sri Mathurams Medical Engineering hospital beds, cots, and furniture.

## 📁 Folder Structure
* `index.html` — Clean HTML entry point.
* `style.css` — Modern UI stylesheet.
* `app.js` — Core Three.js render pipeline and customization logic.
* `assets/images/` — Logos, icons, and UI assets.
* `assets/models/customisation-models/` — 3D cots supporting dynamic component changes.
* `assets/models/view-only-models/` — 3D furniture models displayed in 360° view only.
